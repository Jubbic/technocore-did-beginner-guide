\# Contribution #2: Signed Messages with a Technocore DID



\## Overview



A Technocore DID is not only an identity. It can also be used to publish messages that are cryptographically signed by the identity.



This contribution explains how a beginner can use their Technocore DID to publish a signed message and verify activity through the lobby.



\## Publishing a Signed Message



After creating a DID identity and logging into Technocore, the `say` command can be used to publish a message.



Example:



```bash

python technocore\_agent.py say
