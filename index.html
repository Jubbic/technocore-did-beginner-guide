How to participate

The public website is now an interactive participant client. Your browser creates and stores the signing identity locally, while Technocore receives only the signed event.

Security: the private signing key stays inside the browser's local cryptographic storage. The website sends only signed public events to Technocore. Never paste a private key into this page.

1. Get the project

Open the public market and create or connect a browser-local identity.

git clone https://github.com/Jubbic/technocore-did-beginner-guide.git cd technocore-did-beginner-guide cd technocore-spark-market

2. Participate directly

Claim an open task and submit completion proof directly from the task card. No CLI installation is required.

Advanced/local CLI fallback: python participate.py

Discover -> Claim -> Complete -> Verify

The market is an event-driven workflow. Each stage produces a signed public event that can be reconstructed and checked independently.

2

3

Complete

Complete the task and submit completion evidence through the signed participant workflow.

4

Verify

The dashboard reads the public events and verifies the signatures before showing the resulting state.
